# pvirtual-software-factory

AI Software Factory: agentes autónomos que reciben trabajo desde GitHub,
implementan en sandboxes efímeros en la nube, corren validaciones (CI) y
crean Pull Requests — sin depender de que una laptop esté encendida.

La laptop queda reservada para desarrollo interactivo y decisiones humanas.

## Documentos clave

- [`docs/CONSTITUTION.md`](docs/CONSTITUTION.md) — reglas obligatorias para todo agente autónomo.
- [`docs/vision.md`](docs/vision.md) — plan y arquitectura completa del proyecto.
- [`AGENTS.md`](AGENTS.md) — instrucciones operativas para agentes (convenciones, comandos, estructura).
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — cómo contribuir (branches, commits, PRs).
- [`specs/`](specs/) — especificaciones por feature (Specification Driven Development).

## Principio central

> Implementation MUST NOT precede specification.

Ver la Constitution para el resto de las reglas.
